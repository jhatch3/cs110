My Projects

Project 1 — Turtle Scene (Fundamentals)

A static scene built with Python's Turtle graphics library: a house with trees, clouds, and a yard full of birds. I used variables to control sizes and colors, loops to draw the repeated trees and birds, and conditionals to vary the scene, all over a custom background color. This was my introduction to core programming concepts through creative coding.

Project 2 — Turtle Scene with Functions

The same house, trees, clouds, and yard-with-birds scene, rebuilt by calling the provided building-block functions (draw_rectangle for the house, draw_triangle for the roof, draw_circle for clouds, and more) inside the draw_scene() function. I positioned each element with jump_to() to compose the full scene, practicing function calls and the coordinate system.

Project 3 — Refactored Turtle Scene

A refactor of my Project 2 scene focused on software-engineering principles. I broke the large draw_scene() function into small, single-purpose helpers (draw_house, draw_tree, draw_cloud, draw_bird), removed duplicate code by parameterizing them, then reused those functions to build a more populated version of the scene with extra trees and birds.
